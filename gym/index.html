Weight rule

Use a load you can control cleanly and finish each set with about 2–3 good reps still possible. Do not test maximum lifts. If a movement causes sharp pain, stop that exercise.

This first version is intentionally moderate because the two sessions are on consecutive days. Start with 2 sets per strength exercise for the first two weekends; move to 3 sets only if technique stays solid and recovery feels normal.
